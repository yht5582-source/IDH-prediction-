XGBoost v1.0｜研究模型工作站

目前尚未訓練本院臨床模型。本頁展示已提交的訓練管線及驗證步驟；不會在公開 GitHub Pages 上處理真實病人資料，也不會產生虛構的個人預測機率。

模型輸入

Patient ID

連結歷史 IDH、CAN、DM；不當作直接預測特徵。

Session ID

每次 HD 獨立；僅以當次實際量測時間建立預測點。

Routine only

第一版僅納入常規門診 HD；緊急／臨時／住院透析另外驗證。

60 分鐘 IDH

當下 SBP ≥90，預測接下來 60 分鐘「首次有紀錄 SBP <90」。

開發階段

  1. 資訊室盤點並提供去識別化、帶完整時間戳記資料。
  2. 院內環境執行 CSV 結構檢查、事件標記及特徵生成。
  3. 使用 XGBoost 訓練，分開訓練、驗證及時間外測試療程。
  4. 在驗證集進行機率校準，於獨立測試集回報 AUROC、AUPRC、Brier。
  5. 完成臨床／資安／法規審查後，才能評估是否接入院內推論服務。

資料模型與安全規則

Patient：病人代碼、CAN、跨療程歷史 IDH；Session：獨立療程識別碼、日期、類型、班別、開始／結束時間；Bed assignment：床號及佔用時間；Measurement：當次療程與真實時間戳記。

資料分類：routine 常規、extra 臨時加做、urgent 緊急、inpatient 住院間歇 HD。週一三五第3班即夜班，週二四六不安排常規第3班；非排程使用 X 班別。夜班跨午夜時應在正式院內系統保存完整日期時間。

模型範圍：第一版 XGBoost 只研究常規門診 HD；其他療程保留於病人的完整歷史，需獨立驗證才可外推。

安全：本站為公開、合成、暫存在記憶體的教學原型。禁止輸入真實病人代碼、病歷或臨床資料；不顯示經驗證機率，不建議臨床處置，不自動控制透析機。
